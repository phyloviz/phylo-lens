Advanced branch dragging

Click a node and choose it as the arrangement root in Selected node, then drag a node to translate its loaded branch. This root is a visual choice, not a biological ancestor. Missing roots, disconnected nodes and cycles show a message instead of guessing membership.

Motion, positions and detail changes

Node motion lets connected nodes react to dragging and settle. Turn it off to arrange nodes precisely. Reset positions restores the computed layout and turns Node motion off.

Export scope and limitations

Exports the current view of the loaded slice with its category legend. Increasing the resolution redraws the figure; it does not load more nodes or expand groups. Labels can overlap in dense trees or clip at the image boundary. Legend counts describe the loaded slice, including nodes outside the visible frame.

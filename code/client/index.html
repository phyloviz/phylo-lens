Advanced branch dragging

Click a node and choose it as the arrangement root, then drag a node to translate its loaded branch. This root is a visual choice, not a biological ancestor. Missing roots, disconnected nodes and cycles show a message instead of guessing membership.

Motion, positions and detail changes

Server positions appear first, then Motion relaxes the loaded graph in a worker. Turn Motion off to freeze positions and arrange nodes or groups precisely. Reset pauses Motion and restores the server layout.

Display positions persist within this load. Both simulation and manual dragging stay within 10% of the global span per axis from server positions; viewport queries include this margin. LoD refresh waits while dragging or selecting a region. Detail changes blend positions; expanding a moved group introduces children from its displayed position and inherits its offset. Collapse uses the mean child offset. Motion resumes only if enabled.

Region selection counts loaded nodes at their displayed positions, including collapsed groups; it does not select hidden members individually. Dense queries can still be limited by the node budget.

Only display geometry changes. Topology and edge distances remain unchanged. Geometric lengths do not encode allelic distances; use distance labels.

Export scope and limitations

Exports the current view of the loaded slice with its category legend. Increasing the resolution redraws the figure; it does not load more nodes or expand groups. Labels can overlap in dense trees or clip at the image boundary. Legend counts describe the loaded slice, including nodes outside the visible frame.

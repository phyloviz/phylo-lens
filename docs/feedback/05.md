# Stabilize navigation on large trees with distance labels enabled

Priority: **P1**. Area: Sigma camera / viewport synchronization / labels.

## Evidence and scope

Investigate viewport transformations, snapshot replacement, animation cancellation, renderer rebuilds and event feedback loops. User hardware is not an established cause.

## Dependencies

Can start independently.

## Acceptance criteria

- [ ] Reproduce a recorded pan/zoom/expand sequence on large existing Newick fixtures, with labels on and off.
- [ ] Viewport queries match the actual visible area for wide/tall canvases and navigation beyond original bounds.
- [ ] Snapshots and label toggles preserve camera position and zoom; stale responses never commit.
- [ ] Record dataset size, browser, hardware and timings; include a browser regression for the confirmed cause.

## Delivery

Link implementation PRs here. Close only after regression tests, documentation/public API updates where relevant, and the acceptance criteria are verified. Reported symptoms are not confirmed root causes.

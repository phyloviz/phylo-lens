# Define missing-locus policy and verify typing distances

Priority: **P0**. Area: Server ingest / PhyloLib.

## Evidence and scope

Profiles currently reach Hamming without explicit locus filtering in the service. The reported difference from PHYLOViZ Online has not yet been reproduced.

## Dependencies

Can start independently.

## Acceptance criteria

- [ ] Exclude each locus containing allele 0 in any input profile before Hamming; do not use pairwise deletion.
- [ ] Report retained/excluded loci and reject inputs with no comparable loci.
- [ ] Cover complete profiles, zeros, malformed tables and all-missing loci with regression fixtures.
- [ ] Verify the pinned real PhyloLib runtime and compare a reference matrix with PHYLOViZ Online using recorded settings; do not require an identical MST where ties exist.

## Delivery

Link implementation PRs here. Close only after regression tests, documentation/public API updates where relevant, and the acceptance criteria are verified. Reported symptoms are not confirmed root causes.

GitHub: https://github.com/phyloviz/phylo-lens/issues/9

# Let users choose categories grouped into Other

Priority: **P2**. Area: Palette / pies / legend / public API.

## Evidence and scope

Current category summaries rank frequencies and apply a slice limit; Other is not simply n=1. Color palette capacity also needs reconciliation.

- [ ] Define behavior when explicit choices exceed renderer slice capacity and when data contains a literal Other category.

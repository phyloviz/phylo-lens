# Let users choose categories grouped into Other

Priority: **P2**. Area: Palette / pies / legend / public API.

## Evidence and scope

Current category summaries rank frequencies and apply a slice limit; Other is not simply n=1. Color palette capacity also needs reconciliation.

## Dependencies

[03](03.md)

## Acceptance criteria

- [ ] Explain the automatic frequency/capacity rule and allow explicit category inclusion/exclusion.
- [ ] Preserve category choices and colors across pan, zoom and filtering.
- [ ] Keep Other counts and colors identical across node pies, legends and wheels.
- [ ] Define behavior when explicit choices exceed renderer slice capacity and when data contains a literal Other category.

## Delivery

Link implementation PRs here. Close only after regression tests, documentation/public API updates where relevant, and the acceptance criteria are verified. Reported symptoms are not confirmed root causes.

GitHub: https://github.com/phyloviz/phylo-lens/issues/16

## Confirmed inconsistency — 2026-09-17

Browser validation confirmed that the palette reserves one of its 12 slots for
Others (11 named categories when overflowing), while the metadata wheel keeps
12 named categories and adds Others as a thirteenth slice. Therefore the same
field has different Others totals in the two panels. Reconcile this through a
shared category-selection policy, including tie-breaking and renderer capacity,
before implementing user-controlled grouping. Keep this issue open.

# Separate zoom gestures from cluster expansion and preserve explicit expansion

Priority: **P1**. Area: Interaction / expansion state / viewport API.

## Evidence and scope

Double click currently collapses clusters while Sigma also has default zoom behavior. Ordinary viewport replacement discards expanded patches.

## Dependencies

Can start independently.

## Acceptance criteria

- [ ] Use distinct, documented commands for zoom and collapse, including host API support.
- [ ] Provide expand-all and an option to keep expansion while zooming out.
- [ ] Define persistent expansion state across viewport requests and stale responses.
- [ ] Respect large-graph limits with explicit partial-result feedback; never silently imply everything expanded.

## Delivery

Link implementation PRs here. Close only after regression tests, documentation/public API updates where relevant, and the acceptance criteria are verified. Reported symptoms are not confirmed root causes.

# Export publication figures with controllable edge-distance labels

Priority: **P2**. Area: Label rendering / canvas export / public API.

## Evidence and scope

Distance labels are currently gated by camera ratio, which prevents some whole-tree publication views.

## Dependencies

[05](05.md)

## Acceptance criteria

- [ ] Expose an explicit label visibility policy independent of interactive zoom thresholds.
- [ ] Export selected distances at intended resolution with legible labels and consistent legend.
- [ ] Changing label/export settings must not move the camera.
- [ ] Document clipping, collision and dense-graph limitations; verify real exported images.

## Delivery

Link implementation PRs here. Close only after regression tests, documentation/public API updates where relevant, and the acceptance criteria are verified. Reported symptoms are not confirmed root causes.

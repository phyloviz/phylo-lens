# Improve layout readability and support dragging branches or groups

Priority: **P2**. Area: Server layout / client drag / selection.

## Evidence and scope

Crossing edges and single-node dragging impede manual arrangement. A typing MST has no inherent biological root.

## Dependencies

[02](02.md), [05](05.md)

## Acceptance criteria

- [ ] Benchmark layout alternatives on fixed trees and record overlap/crossing results.
- [ ] Define how a branch is selected (cut edge, explicit root or selected group), including internal-node dragging.
- [ ] Translate the selected members coherently without modifying biological topology or edge-distance values.
- [ ] Preserve positions according to a documented policy across viewport reloads and expansion.
- [ ] Explain that geometric edge length does not automatically encode allelic distance.

## Delivery

Link implementation PRs here. Close only after regression tests, documentation/public API updates where relevant, and the acceptance criteria are verified. Reported symptoms are not confirmed root causes.

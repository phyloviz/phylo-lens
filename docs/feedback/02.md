# Represent equivalent typing profiles as one node with isolate membership

Priority: **P0**. Area: Canonical model / persistence / metadata / rendering.

## Evidence and scope

Equivalent typing profiles are grouped with explicit original-isolate membership, persisted observations and area-proportional node sizing.

## Dependencies

[01](01.md)

## Acceptance criteria

- [x] Group equivalent typing profiles after the missing-locus policy, preserving every original isolate ID.
- [x] Maintain membership through storage, viewport reads, metadata joins and search; handle duplicate IDs and normalized-ID collisions explicitly.
- [x] Size node area proportionally to isolate count and explain the scale; counts must work without ancillary data.
- [x] Keep profile identity distinct from LoD clustering and do not collapse arbitrary zero-length Newick branches.
- [x] Preserve frequency information required by goeBURST tie breaking; validate topology and all-identical-profile input.

## Verified implementation — 2026-09-17

Merged PR #20 implements grouping, original-ID persistence/search, count-based
node area and explicit collision rejection. PR #23 separates isolates, ancillary
observations and profile summaries; PR #2 preserves those identities through
post-render ancillary replacement.

The [reference audit](../validation/typing-distance-reference.md) verifies all
403 original profiles, the exact membership of all 303 groups, and valid minimum
spanning topology. Duplicate profiles remain in the PhyloLib input so their
frequency is not discarded. Exact tie-breaking parity is not asserted.

Server regressions cover duplicate/ambiguous IDs, identical profiles, persistence,
search and ancillary replacement. Browser validation before/after ancillary upload
preserved 303 profiles / 403 isolates and a mixed-country 2:1 distribution. The
radius rule is documented in [client rendering](../CLIENT_RENDERING.md).

This issue's acceptance is complete. Multi-field/missing-value presentation (#11),
UI search races (#12), navigation (#13) and expansion (#14) remain separate work.

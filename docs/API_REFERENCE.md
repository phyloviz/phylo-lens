# HTTP API reference

The complete public reference is maintained in the HTML manual:

- [HTTP API](manual/http-api.html): all endpoints, request fields, captured
  examples, revision behavior and errors.
- [HTTP field reference](manual/http-types.html): all request and response models.
- [OpenAPI schema](manual/assets/openapi.json): downloadable schema for tooling.
- [Browser API](manual/browser-api.html): the npm viewer API.

A running service also exposes `/openapi.json` and interactive `/docs`.
See [server setup](../code/server/README.md) for installation and configuration.

HTTP field reference

These tables list the request and response shapes published by the service. Follow a type link to inspect nested fields. Required describes the schema. Some routes omit null response values, including a root’s parent_id; allow for those omitted nullable fields when reading JSON. Arrays and maps supplied by default factories may have no explicit OpenAPI default.

Download the OpenAPI schema for client generation. See the HTTP API for examples and rules that cannot be expressed by field types alone.

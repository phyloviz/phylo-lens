Getting started

Follow this example to load a small tree and add country information. If PhyloLens is already running, skip to Load a tree.

Run PhyloLens locally#

Start the API service from the repository root:

python -m pip install -e 'code/server[test,dev]'
python -m uvicorn phylo_lens_server.main:app --host 127.0.0.1 --port 8000

In a second terminal, start the browser application:

cd code/client
npm ci
npm run dev

Open the address printed by Vite. The development application forwards service requests to port 8000. Newick preparation requires Graphviz sfdp. Typing-data preparation also requires Java and the configured PhyloLib JAR. The service Docker image includes these dependencies. See the server installation instructions for configuration and deployment.

Load a tree#

  1. Save the following Newick text as example.nwk.
  2. Open the Data panel and choose Newick.
  3. Select the file and apply the input.
((PT-01:1,PT-02:1)Lineage:1,ES-01:2)Root;

Drag the background to move the view. Use the mouse wheel to zoom. Select a node to display its information in the right-hand panel.

Add observations#

Save the following table as countries.csv. Supply it as ancillary data and choose ID as its identifier column. 

ID,country
PT-01,Portugal
PT-02,Portugal
ES-01,Spain

In Appearance, choose country as the colour field. The labels in the identifier column must match the labelled nodes or original typing isolates. Unmatched rows are reported as warnings.

Continue exploring#

Search for PT-01 to locate the node. Larger trees can be explored by zooming or expanding groups. To save a figure, open Export view and download a PNG.

For a larger example, use the documentation example files. Continue to Display and navigation for screenshots of these operations.

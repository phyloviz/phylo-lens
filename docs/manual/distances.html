PhyloLens / Distance operations

Distance operations

PhyloLens has three distance settings with different effects. The inference level constructs the typing tree; a cutoff splits tree edges; additional connections annotate an existing tree.

Maximum inference level

For typing data, goeBURST (up to nLV) limits the locus-variant levels considered when selecting tree edges. Maximum nLV 3 allows links with up to three differing retained loci. The result may be a forest. Full MST uses all levels to construct one connected tree.

Choose this option in the Data panel before applying the input. See Typing data.

Tree distance cutoff

A cutoff keeps tree edges whose distance is less than or equal to the selected value. Longer edges are removed, but every node remains. The resulting components are prepared as separate trees.

A blank value disables the cutoff. Zero is a valid cutoff. An edge with an unknown distance cannot be interpreted as zero. Applying a cutoff reloads the data and rebuilds the layout; previous manual arrangements are lost.

Additional connections

The nLV or distance-connection controls add an overlay to the prepared tree. Connections are restricted to nodes within the same prepared component. They do not join components, change branch membership or alter the springs used by tree layout.

Input Overlay distance
Typing data Number of differing retained loci (Hamming distance).
Weighted Newick Sum of branch lengths along the existing tree path.

Pairs at exactly the threshold are included. Self-connections and duplicate tree edges are excluded. Connections to grouped or manually hidden endpoints are omitted from the visible overlay; the total query count and visible count can differ.

The overlay can contain cycles. This does not change the underlying tree. Its metric and threshold are included in the PNG caption. Full rules and algorithm costs are in the distance reference.

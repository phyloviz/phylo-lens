Maintaining this manual

The manual consists of checked-in HTML pages, one stylesheet and a small optional search script. It has no build step, theme package, external fonts or CDN dependencies.

Edit the pages

Edit the files in docs/manual/ directly. Keep instructions short and describe an action followed by its visible result. Use the control names shown in the application. Explain the meaning of a count or distance where it first appears.

The navigation is ordinary HTML in each page. When adding a page, update the contents and previous/next links in the existing pages. Preserve descriptive page titles, heading IDs, image descriptions and the current-page marker.

Public API signatures and deployment settings remain in the repository READMEs and reference documents. Link to those sources instead of maintaining another complete copy here.

Preview and check

Open docs/manual/index.html directly to read the manual. For full-text search, serve the directory over HTTP from the repository root: 

python -m http.server 8010 --bind 127.0.0.1 --directory docs/manual

Open http://127.0.0.1:8010/. Search reads the manual pages from the same server. Navigation and content remain usable without JavaScript.

Run the dependency-free link and HTML check before committing:

python scripts/check_manual.py

Update screenshots

Use synthetic example data. Start the real application service, install the client and evaluation-browser dependencies, then run: 

cd code/client
REQUIREMENTS_API_URL=http://127.0.0.1:8000 DOC_INCLUDE_TYPING=1   node tests/browser/libraryCompletion.mjs --screenshots

Typing captures require the configured PhyloLib JAR. Captures are written to output/playwright/library-completion/. Inspect them and copy the selected images into docs/manual/assets/screenshots/. Update image dimensions and captions when needed. The capture also checks technical rerooting through the service.

Publish on GitHub Pages

In the repository's Settings → Pages, select GitHub Actions as the source. The Documentation workflow validates the manual for pull requests. On main, it uploads docs/manual/ directly and deploys the Pages artifact. No Python packages need to be installed for publication.

The configured address is https://phyloviz.github.io/phylo-lens/. The manual is a static website. It does not run the preparation service or an embedded live viewer.

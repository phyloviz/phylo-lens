Browser types

These types are exported from @phyloviz/phylo-lens. Select a linked type name to inspect it. The Browser API describes view options, callbacks and method behavior.

Properties marked readonly should be treated as read-only. Optional properties use ?. Identifier brands distinguish string roles; a brand does not prove that an identifier exists.

Appearance and export#

GraphDisplayOptions

An exported display-options shape. The current public view does not expose a general updateDisplayOptions() method. 

export interface GraphDisplayOptions {
  readonly nodeLabels?: boolean;
  readonly edgeDistanceLabels?: boolean;
  /** Auto retains the interactive zoom threshold; always shows enabled labels at every zoom. */
  readonly edgeDistanceLabelPolicy?: 'auto' | 'always';
  /** Inclusive numeric distance bounds; omitted bounds are open. */
  readonly edgeDistanceLabelMin?: number;
  readonly edgeDistanceLabelMax?: number;
  /** Encode distance with grayscale at constant edge width. */
  readonly distanceWeightedEdges?: boolean;
}

GroupSizeMappingOptions

export type GroupSizeMappingOptions = {
  /** Radius at the reference zoom before adding represented-node area. Default: 6. */
  readonly minimumSize?: number;
  /** Additional squared-radius units per represented node after the first. Default: 1. */
  readonly areaPerNode?: number;
  /** Upper radius approached gradually as counts grow. Default: 12. */
  readonly maximumSize?: number;
};

PieCategoryGrouping

Keys are category identities from pieDistribution(). Values choose a separate slice or the Other group. 

export type PieCategoryGrouping = Readonly<Record<string, 'separate' | 'other'>>;

PieMappingOptions

export type PieMappingOptions = {
  readonly enabled?: boolean;
  readonly fields?: readonly string[];
  readonly palette?: readonly string[];
  readonly categoryColors?: Readonly<Record<string, string>>;
  /** Separate choices reserve up to 11 slots in stable key order, even offscreen.
   * Excess choices and categories marked other aggregate in the gray Other slice.
   * For multiple fields, keys are the observed combination identities from pieDistribution.
   */
  readonly categoryGrouping?: PieCategoryGrouping;
};

PngExportOptions

export interface PngExportOptions {
  readonly scale?: number;
  /** Current follows the live label policy; all ignores zoom; none hides distances. */
  readonly edgeLabels?: 'current' | 'all' | 'none';
  /** Label only these edge IDs; geometry is preserved. Omit to include every distance. */
  readonly edgeIds?: readonly string[];
  /** Font size in logical pixels before scaling (6–72). */
  readonly edgeLabelSize?: number;
  /** Include category observations and aggregate-symbol explanations in publication exports unless false. */
  readonly includeLegend?: boolean;
}

Identifiers and statuses#

The declarations use a private symbol to mark each string’s role. Call the exported identifier helpers instead of recreating that marker.

ClusterId

A branded string. Use toClusterId() for an existing cluster identifier. 

export type ClusterId = string & { readonly [identifierKind]: 'cluster' };

DatasetId

A branded string. Use toDatasetId() for an existing dataset identifier. 

export type DatasetId = string & { readonly [identifierKind]: 'dataset' };

GraphLayoutStatus

export const GraphLayoutStatus = {
  PENDING: 'pending',
  REFINING: 'refining',
  READY: 'ready',
  DEGRADED: 'degraded',
  FAILED: 'failed',
} as const;

export type GraphLayoutStatus = (typeof GraphLayoutStatus)[keyof typeof GraphLayoutStatus];

GraphPrepareJobStatus

export const GraphPrepareJobStatus = {
  PENDING: 'pending',
  READY: 'ready',
  FAILED: 'failed',
} as const;

export type GraphPrepareJobStatus = (typeof GraphPrepareJobStatus)[keyof typeof GraphPrepareJobStatus];

LayoutVersion

A branded string. Use toLayoutVersion() for an existing published version. 

export type LayoutVersion = string & { readonly [identifierKind]: 'layout-version' };

NodeId

A branded string. Use toNodeId() when starting with a string; the helper does not query or normalize the node. 

export type NodeId = string & { readonly [identifierKind]: 'node' };

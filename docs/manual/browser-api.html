Browser API

Use the browser package to embed a tree in your application. Import its functions and types from @phyloviz/phylo-lens. The package uses ES modules and includes TypeScript declarations.

Create a view#

Install the package, give the container a width and height, then create the view. 

npm install @phyloviz/phylo-lens
import { createPhyloLensView } from '@phyloviz/phylo-lens';

const container = document.getElementById('tree');
if (!(container instanceof HTMLElement)) throw new Error('Missing tree container.');
container.style.height = '600px';

const view = createPhyloLensView({ container, apiUrl: '/phylo-lens' });
await view.load({ content: '(A:1,B:2)Root;', sourceFormat: 'newick' });

Supply exactly one of apiUrl and graphClient. An empty apiUrl uses the current origin; /phylo-lens uses a reverse-proxy prefix. A full URL connects to another origin, which must allow your page through CORS.

Option Type Purpose
container HTMLElement Required. The element that contains the viewer.
apiUrl string Base URL or path for the companion service.
graphClient GraphClient Your own data adapter. See Custom adapters.
onNodeSelected callback Receives the selected node and whether it can be expanded or folded.
onExpansionChanged callback Receives the current expansion state after the displayed tree changes.
onError callback Receives errors reported by the viewer. Also catch rejected promises.
onInteractionFeedback callback Receives a short explanation when an interaction needs feedback.

Load options#

await view.load(options) replaces the current dataset. With the default adapter, it checks service compatibility, waits for preparation, reads the first view and renders it before resolving. A newer load supersedes an older pending load.

Option Default Purpose
content required Newick text or a tab-separated allelic-profile table.
name uploaded-dataset Dataset name sent to the service.
sourceFormat newick newick or typing_data.
typingOptions Full MST Use { algorithm: "goeburstfullmst" } or { algorithm: "goeburst", nlv: 3 }. The latter defaults to level 3. Only valid for typing data.
distanceCutoff none Keep edges at or below this distance and prepare the resulting forest. Zero is valid; all edge distances must be known.
ancillarySchema [] Field declarations: { key, type }, with string, number, boolean or null types.
ancillaryByNodeId {} Sample information keyed by node or original typing-isolate identifier. Direct values take precedence over the supplied table.
ancillaryData none A table with { content, format, joinColumn }. Format is auto, csv or tsv.
visualMapping default mapping Colour, size and pie-chart options. See Appearance.
sfdpOptions server defaults Graphviz layout settings. See SfdpOptions and their defaults and limits.
lodPreparation.smallComponentThreshold 64 Keep components of this size or smaller explicit at every prepared tier. Set 0 to disable this preparation rule.
lod.maxNodes unbounded Optional limit for viewport and expansion reads. Check for partial expansion results.
lod.representationSpacingPx 24 Preferred spacing in CSS pixels for automatic detail selection.
lod.smallTreeThreshold 2500 Start a tree of this size or smaller at the finest detail tier. This is a viewer preference, separate from preparation policy. 
await view.load({
  content: profilesTsv,
  sourceFormat: 'typing_data',
  typingOptions: { algorithm: 'goeburst', nlv: 3 },
  ancillaryData: { content: countriesCsv, format: 'csv', joinColumn: 'ID' },
  visualMapping: { colorField: 'country', pie: { enabled: true, fields: ['country'] } },
});

Loading prepares a new layout and clears previous manual arrangements. For a new table on the same tree, use applyAncillaryData() instead.

Callbacks and identifiers#

Register callbacks when creating the view:

const view = createPhyloLensView({
  container,
  apiUrl: '/phylo-lens',
  onNodeSelected: selection => {
    console.log(selection.nodeId, selection.clusterId, selection.expandable);
  },
  onExpansionChanged: state => console.log(state.partial, state.renderedNodeCount),
  onError: error => console.error(error),
  onInteractionFeedback: message => console.log(message),
});

The selection contains nodeId and clusterId (each may be null), expandable, and optional collapsible and manuallyCollapsed flags. The expansion callback receives ExpansionState.

TypeScript distinguishes node, cluster, dataset and layout identifiers. Use toNodeId(), toClusterId(), toDatasetId() and toLayoutVersion() to assign the right role to a string. These helpers do not look up a node or normalize a label. 

import { toNodeId, toClusterId } from '@phyloviz/phylo-lens';
await view.focusNode(toNodeId('a'));
await view.expandCluster(toClusterId('lod_0_a'));

The method descriptions below use the declared return types. PositionedGraph describes a returned snapshot; it is not a package-root export. You can use the inferred result without importing that name. Its shape is documented separately.

Loading and disposal#

load()

load: (options: PhyloLensLoadOptions) => Promise<void>

Prepare and display the supplied dataset. Service, preparation and initial viewport failures reject the promise.

dispose()

dispose: () => void

Release the renderer, listeners and pending work when removing the view. Repeated calls are safe. Other methods reject or throw after disposal.

Appearance and sample data#

updateVisualMapping()

updateVisualMapping: (mapping: VisualMappingOptions) => void

Replace the current appearance settings and schedule a refresh. Include any colour, size or palette settings you want to keep. Requires a loaded tree.

applyAncillaryData()

applyAncillaryData: (data: AncillaryTableInput) => Promise<PhyloLensAncillaryResult>

Replace the current sample table and field schema in a new server version. The result reports matchedNodeCount and warnings. The promise resolves after the updated view is shown. Coordinates, camera and manual arrangements are kept; omitted fields and unmatched records do not keep old values. A failed update keeps the previous view usable. Root and table changes are serialized. 

view.updateVisualMapping({
  colorField: 'country',
  size: { field: 'year', scale: 'linear' },
  pie: { enabled: true, fields: ['country'] },
});

await view.applyAncillaryData({
  content: 'ID,country\nA,Portugal\nB,Spain\n',
  format: 'csv',
  joinColumn: 'ID',
});

Visual mappings support colorField, size, groupSize, palette and pie. With no selected colour field, ordinary profiles use a neutral colour. Pie settings include fields, palette, category colours and grouping. See VisualMappingOptions and PieMappingOptions.

Search and focus#

searchNodes()

searchNodes: (query: { query: string; limit?: number; }) => Promise<GraphSearchResult>

Search the loaded dataset for an identifier or sample value. Results contain matches and totalCount. Each match identifies a profile node, with optional coordinates and cluster ID. Multiple isolates sharing a profile produce one profile result.

focusNode()

focusNode: (nodeId: NodeId, coordinates?: { readonly x: number | null; readonly y: number | null; readonly clusterId?: ClusterId | null; }) => Promise<PositionedGraph>

Locate and centre a node. Supply coordinates from a search result to avoid another lookup. A newer focus, load or disposal supersedes pending focus work.

cancelPendingFocus()

cancelPendingFocus: () => void

Cancel a pending focus when clearing your search input or dismissing results. 

const results = await view.searchNodes({ query: 'A', limit: 25 });
const match = results.matches[0];
if (match) {
  await view.focusNode(match.node_id, {
    x: match.x ?? null, y: match.y ?? null, clusterId: match.cluster_id,
  });
}

Search-match fields retain the documented names node_id, cluster_id and matched_text. Other adapter result fields generally use camelCase.

Expansion and folding#

expandCluster()

expandCluster: (clusterId: ClusterId) => Promise<ExpansionResult>

Request the members of an automatic detail group. Check the returned status before reporting that expansion is complete.

collapseCluster()

collapseCluster: (clusterId: ClusterId) => ExpansionState

Collapse an explicitly expanded group and return the resulting expansion state.

collapseBranch()

collapseBranch: (nodeId: NodeId) => ExpansionState

Fold descendants of an ordinary node, retaining the branch root. Branch membership follows the technical root.

expandBranch()

expandBranch: (nodeId: NodeId) => ExpansionState

Restore a manually folded branch.

expandAll()

expandAll: () => Promise<ExpansionResult>

Request the finest detail. A supplied lod.maxNodes budget may produce a partial result. A newer operation can supersede this one.

collapseAll()

collapseAll: () => Promise<ExpansionResult>

Return to the coarsest detail tier.

setKeepExpanded()

setKeepExpanded: (keep: boolean) => ExpansionState

Keep explicit expansions across view changes and pin the current detail tier. Passing false resumes automatic detail selection.

getExpansionState()

getExpansionState: () => ExpansionState

Read the current expansion state, including whether the displayed result is partial.

ExpansionResult has status complete, partial or superseded. It also includes keepExpanded, expandedClusterIds, allExpanded, partial, renderedNodeCount, optional maxNodes and manuallyCollapsedBranchCount.

Technical roots and distance connections#

canSetTechnicalRoot()

canSetTechnicalRoot: () => boolean

Check whether the adapter supports technical-root changes.

getTechnicalRoots()

getTechnicalRoots: () => readonly string[]

Read the current root IDs, one per component.

setTechnicalRoot()

setTechnicalRoot: (nodeId: NodeId | null) => Promise<{ readonly technicalRoots: readonly string[]; readonly defaultRoots: readonly string[]; }>

Choose a root for its component, or pass null to restore every preparation root. Returns technicalRoots and defaultRoots after the updated view loads. Edges, coordinates and observations are preserved. Changed orientation clears folds, explicit expansions and distance overlays. See the technical-root guide for details.

setDistanceConnections()

setDistanceConnections: (options: DistanceConnectionOptions | null) => Promise<PositionedGraph>

Add or replace the distance overlay. Pass null to remove it without a server request. threshold is finite and nonnegative; typing thresholds are whole numbers. maxConnections defaults to 50,000. Exceeding the limit rejects the replacement and preserves the previous overlay. Links remain within the prepared components. 

if (view.canSetTechnicalRoot()) {
  await view.setTechnicalRoot(toNodeId('a'));
  await view.setTechnicalRoot(null); // Restore all default roots.
}
await view.setDistanceConnections({ threshold: 2, maxConnections: 10000 });

Technical rerooting preserves the tree’s connections. It does not implement PHYLOViZ founder selection. Read Technical roots and Distance operations before interpreting the result.

Forest components#

listComponents()

listComponents: (page?: { after?: number; limit?: number; }) => Promise<GraphComponentsResult>

Read a page of components. Pass after from the previous nextCursor and an optional limit. The default service limit is 50, with a maximum of 200. A custom adapter without component listing returns an empty list.

selectComponent()

selectComponent: (component: GraphComponent | null) => Promise<PositionedGraph>

Show a component returned by listComponents(), or pass null for the forest overview. Each panel keeps its camera and manual arrangements.

getComponentId()

getComponentId: () => string | undefined

Read the active component ID. The overview returns undefined.

Layout and dragging#

relaxLayout()

relaxLayout: () => void

Run a finite layout relaxation on the loaded view.

stopLayout()

stopLayout: () => void

Stop movement, keep the current positions and disable automatic relaxation.

getLayoutMotionState()

getLayoutMotionState: () => LayoutMotionState

Read automatic and running flags.

setLayoutMotionHandler()

setLayoutMotionHandler: (handler: ((state: LayoutMotionState) => void) | null) => void

Receive changes to the motion state, or pass null to remove the callback.

setMotionEnabled()

setMotionEnabled: (enabled: boolean) => void

Enable or disable automatic layout relaxation. Layouts start in manual mode.

isMotionEnabled()

isMotionEnabled: () => boolean

Read whether automatic relaxation is enabled.

setDragSelection()

setDragSelection: (selection: DragSelection) => void

Choose individual-node, rooted-branch or selected-group dragging. This affects arrangement only; the branch-drag anchor does not change the technical root.

resetLayoutEdits()

resetLayoutEdits: () => void

Restore the active panel’s prepared positions, pause motion and return to individual-node dragging. Resetting the overview restores all components. 

view.setDragSelection({ kind: 'node' });
view.setDragSelection({ kind: 'branch', rootId: 'root' });
view.setDragSelection({ kind: 'group', nodeIds: ['a', 'b'] });

PNG export#

exportPng()

exportPng: (options?: PngExportOptions) => Promise<Blob>

Return a Blob of the current visible view. This does not start a download, move the camera or load finer detail. The export options control scaling, distance labels and the legend.

Option Values Purpose
scale 1–4 Multiplies the viewport’s CSS dimensions.
edgeLabels current | all | none Follow the live distance-label policy, show all distances or hide them.
edgeIds string[] Restrict distance labels to these edges; keep all geometry.
edgeLabelSize 6–72 Distance-label font size before scaling.
includeLegend boolean Include category and aggregate-symbol explanations unless false. 
const blob = await view.exportPng({ scale: 2, edgeLabels: 'all', includeLegend: true });
const url = URL.createObjectURL(blob);
const link = document.createElement('a');
link.href = url;
link.download = 'tree.png';
link.click();
setTimeout(() => URL.revokeObjectURL(url), 1000);

Custom adapters#

Supply GraphClient to connect the viewer to another service or local data. Only prepareGraph and readViewport are required. Preparation resolves when viewport reads are available. A viewport result describes the requested dataset and version, positions, tree edges, counts and sample information.

The optional operations are searchGraph, readRegion, applyAncillaryData, readComponents, readDistanceConnections and setTechnicalRoot. Unsupported operations reject with an explanation; component listing returns an empty list when unavailable. Expose controls for the capabilities your adapter provides.

The adapter types describe every request and result. Keep a layout version unchanged only while its data, geometry, orientation and detail groups remain unchanged. Return tree edges with both endpoints present and preserve original isolate observations.

createGraphClient(options)

Use the default HTTP adapter with a custom fetch function, for example to add credentials: 

import { createGraphClient, createPhyloLensView } from '@phyloviz/phylo-lens';
const graphClient = createGraphClient({
  baseUrl: '/phylo-lens',
  fetchImpl: (url, init) => fetch(url, { ...init, credentials: 'include' }),
});
const view = createPhyloLensView({ container, graphClient });

It returns Required<GraphClient> and handles compatibility checks, job polling, response validation and wire-field mapping. GraphPrepareOptions lets direct adapter callers set polling callbacks, interval and timeout. The defaults are 1,000 ms between polls and no overall wait timeout. The view’s load() method does not expose these polling options.

Observation utilities#

pieDistribution(observations, fields)

Group weighted observations by one or more fields. Returns category objects with key, category, label, value and optional missing. Each observation contributes its count once, including missing values. Results are ordered by count, then key. Use the returned keys for pie.categoryColors and pie.categoryGrouping. 

import { pieDistribution } from '@phyloviz/phylo-lens';
const categories = pieDistribution([
  { values: { country: 'Portugal' }, count: 2 },
  { values: { country: 'Spain' }, count: 1 },
], ['country']);

Errors and compatibility#

Catch rejected method promises even when you register onError. The default adapter checks API compatibility through /health; successful checks are kept for the lifetime of the view. The supported contract is SUPPORTED_PHYLO_LENS_API_VERSION = '1'.

Exported error Meaning
PhyloLensServiceUnavailableError The service-information request could not reach the service.
PhyloLensServiceProtocolError The service-information response is invalid.
IncompatiblePhyloLensServiceError The API version differs. Read expectedApiVersion and receivedApiVersion.

Preparation, request-validation and missing-capability errors may be ordinary Error instances. A new load or disposal prevents older work from replacing the current tree. Dispose the view when removing it from the page.

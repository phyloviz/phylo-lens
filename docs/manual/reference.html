Algorithms and references

PhyloLens uses PhyloLib for typing-data inference and Graphviz for the initial global layout. Rooted indexes and detail groups support tree navigation and semantic zoom. The algorithm references distinguish published methods from project-specific adaptations and list their sources.

Technical roots are computational choices. A typing-derived MST does not by itself establish ancestry. Original isolates, equivalent typing profiles and visual representatives have different meanings; counts should be interpreted accordingly.
